# Application preferences

Open **File → Preferences…** in the project explorer to set defaults shared by
all projects on this nfit installation. These preferences are stored locally and
are not included in project files.

## Data viewer

The **Data viewer** tab controls defaults for newly opened data viewers. **Figure
font size** sets the size, in points, of plot labels, tick numbers, and titles.
**Axes line width** sets the thickness, in points, of plot axes and tick marks.
The defaults are 12 pt and 1.5 pt. Existing viewers keep their current settings;
these values do not change saved plot recipes.

The tab also offers optional data preloading. See the
[data viewer guide](data_viewer.md) for its effect on opening time and memory use.

## Colormaps

The **Colormaps** tab selects defaults for continuous plots and waterfall traces
and provides the shared folder for custom RGB colormaps. See
[Custom colormap files](data_viewer.md#custom-colormap-files) for the supported
file format.

## Performance

The **Performance** tab sets application-wide CPU and RAM limits for numerical
work. See [Performance settings and benchmarks](performance.md#performance-preferences-and-benchmarks).
