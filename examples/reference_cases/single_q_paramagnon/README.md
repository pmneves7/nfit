# Single-Q paramagnon reference case

This directory stores the compact reference output generated by:

```bash
python examples/synthetic_single_q_fit.py
```

The example uses a fixed random seed, known synthetic parameters, and a measured
intensity model built from two separate layers:

1. `paramagnon_chipp`, which returns chi''(Q,E).
2. `intensity_from_chipp`, which applies the Bose factor, scale, and background.

The JSON summary is intended for human checking and future regression validation.
