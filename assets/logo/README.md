# nfit logo sources

Preserve these original design files for future editing:

- `nfit.ai`: Adobe Illustrator source (PDF-compatible file).
- `nfit-01.svg`: full wordmark, with the neutron sphere and “n” followed by “fit”.
- `nfit-02.svg`: neutron sphere with “n”, for the application icon.

Both SVGs contain live Arial text; the wordmark also uses Charm. The text is
not converted to outlines, so rendering depends on installed fonts. Each SVG
contains an embedded 512 × 512 PNG sphere, rather than a vector sphere.

Keep the Illustrator source editable. Before integrating the logos into the
application or documentation, export separate SVG copies with text converted
to outlines (Illustrator: select the text, then Type → Create Outlines).
Check the exported artboard bounds and small icon sizes. Preserve these
originals when creating outlined SVGs or platform icon files.
